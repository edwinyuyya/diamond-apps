# Brand profiles

Read this file whenever the user names a brand (Nexora, BBQIU, Rejeki Utama AC) or the topic clearly belongs to one. Apply the brand's voice, visuals, CTA and hashtags. Fields marked `[ISI]` are unknown: use a sensible default, and ask the user once at the end to fill them in. Never invent prices, awards, halal/health claims, guarantees or customer counts.

If the user asks for a brand not listed, ask for: what is sold, who buys it, tone, main CTA, and add a new profile here.

## Multi-brand workflow

- Keep each brand's content separate: one caption, hashtag set and CTA per brand; never mix brand names in one video.
- When asked for a weekly plan across brands, output a table: `day | brand | pillar | hook | format | CTA`, balanced (e.g. 3 posts/brand/week) and spread across best posting times.
- If the user's app sends captions through an API, output caption + hashtags as separate fields so they can be posted automatically.
